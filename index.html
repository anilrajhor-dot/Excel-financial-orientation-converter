Choose a PDF or load the sample table.

Reconstruction

Structure-first conversion: text items are grouped into visual rows using their Y positions, then into cells using X positions. The app detects whether the source is naturally a vertical table (e.g. 20 × 3) or a wide table (e.g. 3 × 20) before rendering. Numeric strings are kept as atomic values and are never split merely to fit the screen.

Preview

Wide tables scroll horizontally. Cell values are not altered to fit the viewport.
