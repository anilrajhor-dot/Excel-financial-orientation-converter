Excel Financial Orientation Converter — Version 6.0

Upload .xlsx, .xls, .csv or PDF.
PDF mode reconstructs digitally generated financial-result tables using PDF word positions.
Select:
1. Dates/Years ↓ + Particulars →
2. Keep detected orientation
3. Particulars ↓ + Dates/Years →

IMPORTANT:
- PDF text/table extraction works best with digitally generated PDFs.
- Scanned/image-only PDFs need OCR and are not guaranteed to convert correctly.
- The app uses SheetJS and PDF.js from CDN, so GitHub Pages needs internet access for those libraries.
- Upload ALL files in this folder to the repository root, preserving the icons folder.
